# Neon Sumi everywhere

Every file here is generated from `design/tokens.json`. Change a colour there, run `python3 tools/build_themes.py`, and every port follows; `--check` lists colours in the repo that are not tokens.

| Tool | File | Install |
| --- | --- | --- |
| Claude Code | `plugins/neon-sumi/themes/neon-sumi.json` | ships with the plugin: `/theme` → Neon Sumi (or copy it to `~/.claude/themes/`) |
| Zed | `themes/zed/neon-sumi.json` | copy to `~/.config/zed/themes/`, then pick Neon Sumi |
| iTerm2 | `themes/iterm2/Neon Sumi.itermcolors` | Settings → Profiles → Colors → Color Presets → Import |
| Ghostty | `plugins/neon-sumi/statusline/ghostty/neon-sumi.ghostty` | add `config-file = ~/.claude/neon-sumi/ghostty/neon-sumi.ghostty` to the Ghostty config (palette kept in step) |
| Obsidian | `obsidian/theme/` | copy to `.obsidian/themes/Neon Sumi/` (palette kept in step) |
| Web | `design/tokens.css` | `--ns-*` custom properties |
