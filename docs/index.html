# in Claude Code: add the marketplace, install, let the skill wire it up
/plugin marketplace add Danneftw1/neon-sumi
/plugin install neon-sumi@neon-sumi
/neon-sumi:install

The last step copies the files to ~/.claude/neon-sumi/, renders once, and asks before it touches settings.json (with a backup). Needs Python 3.9+ as python3 on your PATH, a Nerd Font and git; gh lights up the GitHub rows.
